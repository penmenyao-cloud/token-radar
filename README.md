A token launch radar: it reads a frozen snapshot of 758 DeFi protocols, ranks the 200 pre-token ones by an implied value computed from TVL, seven-day growth and age with no token on record, and renders a filterable dashboard with a detail view and a concrete farm plan for each protocol. Protocols whose token already trades are shown apart, with their market cap, never ranked by implied value.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
